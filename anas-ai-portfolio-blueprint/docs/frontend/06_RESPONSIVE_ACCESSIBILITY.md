# Responsive and Accessibility Requirements

## Breakpoints
Design mobile-first. Validate common phone, tablet, laptop, wide desktop widths.

## Critical mobile flows
- navigation;
- AI chat;
- CV viewer;
- project deep dive;
- Job Fit Analyzer textarea/results;
- Select popovers;
- admin content editing where practical.

## Accessibility
Target WCAG 2.2 AA behavior.

Required:
- semantic landmarks;
- skip link;
- keyboard navigation;
- visible focus;
- focus trap in modals;
- focus restoration;
- screen-reader labels;
- meaningful button names;
- no icon-only ambiguity;
- sufficient contrast;
- reduced-motion support;
- error association;
- status announcements for async actions;
- copy action announcement;
- streaming-chat accessibility strategy.

Accessibility failures in core navigation/auth/chat are release blockers.
