# Admin Theme Control

Expose constrained design tokens:
- accent token;
- neutral palette choice;
- light/dark surface tokens;
- border radius preset;
- content width preset;
- motion intensity;
- section spacing preset.

Do not expose raw HTML/CSS/JS fields.

Changes:
- validated;
- versioned;
- previewable;
- cache invalidated;
- audit logged.

The default visual direction remains minimal even when admin changes tokens.
