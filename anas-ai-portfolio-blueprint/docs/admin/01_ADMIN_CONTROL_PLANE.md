# Admin Control Plane

The Admin Panel is a core product, not an afterthought.

## Navigation areas
- Dashboard
- Content
- Sections
- Projects
- CV
- Social
- Navigation
- Localization
- Theme
- AI Providers
- AI Models
- Model Assignments
- Prompts
- RAG Configuration
- Indexing
- Evaluations
- Feature Flags
- Audit Logs
- System Health

Visible labels come from dynamic UI text.

## Principles
- privileged;
- server authorized;
- reversible where possible;
- preview before publish;
- explicit destructive confirmation;
- validation;
- audit;
- health feedback.

## Dashboard
Show actionable status:
- missing translations;
- failed indexing jobs;
- AI provider health;
- pending draft changes;
- evaluation regression;
- missing required config;
- current index version.
