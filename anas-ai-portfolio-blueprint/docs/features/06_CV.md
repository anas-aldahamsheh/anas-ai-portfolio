# CV Feature

Public route capability: `/cv`.

## Public
- display current published PDF in a responsive viewer;
- fallback accessible download action if browser PDF rendering is unavailable;
- download button;
- correct filename and content type;
- cache policy supports replacement without stale CV.

## Admin
- upload PDF;
- validate MIME, magic bytes, file size and malware/security policy;
- create version;
- preview;
- publish a version;
- rollback to older version;
- archive/delete unneeded version according to retention rules.

## Storage
Binary is stored in BlobStorage.
Database stores metadata and the active published pointer.

No CV content or file path is hardcoded.
