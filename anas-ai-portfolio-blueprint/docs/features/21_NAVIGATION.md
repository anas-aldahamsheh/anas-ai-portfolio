# Dynamic Navigation

Navigation entries are data.

Each entry:
- semantic destination/type;
- optional internal route reference;
- optional safe external URL;
- localized label;
- icon key;
- order;
- visibility;
- auth visibility rule only if truly needed.

Admin:
- create;
- edit;
- reorder;
- hide;
- delete.

Public navigation must continue to work in RTL/LTR and mobile.
