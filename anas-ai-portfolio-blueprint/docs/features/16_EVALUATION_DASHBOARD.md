# Evaluation Dashboard

## Public view
May show approved aggregate quality metrics and methodology descriptions.

## Admin view
Shows:
- dataset version;
- model version;
- prompt version;
- embedding index version;
- retrieval metrics;
- generation metrics;
- latency;
- failure categories;
- regression comparison.

## Metrics
Use measured values only:
- Recall@K;
- Precision@K;
- MRR/nDCG where useful;
- context relevance;
- citation correctness;
- faithfulness;
- answer relevance;
- task success;
- language parity;
- latency.

Never invent impressive percentages.
