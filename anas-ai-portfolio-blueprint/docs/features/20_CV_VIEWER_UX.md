# CV Viewer UX

Desktop:
- page title/metadata;
- embedded PDF region;
- Download action remains visible;
- optional full-screen/open action.

Mobile:
- if embedded PDF support is poor, show an accessible document preview/fallback and strong Download/Open action;
- never trap the user in a tiny unreadable iframe.

Admin:
- preview current candidate before publish;
- display version/date/file metadata;
- publish/rollback.

All labels are dynamic/localized.
