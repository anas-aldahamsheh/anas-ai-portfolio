# GitHub + LinkedIn Profile Interactions

Treat social profiles as dynamic content records.

## Click behavior
Clicking the GitHub or LinkedIn action opens a styled popover/card.

Card displays, if configured:
- platform icon;
- account/handle;
- canonical URL;
- Copy;
- Open Profile.

## Copy
Copy the canonical URL through Clipboard API.
Show accessible success feedback.

## Open
Open new safe tab with `noopener,noreferrer`.

## Admin
Can edit/remove/reorder/hide social profiles.
No profile URL appears in source code.
