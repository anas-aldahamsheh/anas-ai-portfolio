# Guest-First Access

Goal: recruiters can use the entire public portfolio without creating an account.

## Public guest capabilities
- all published pages;
- CV viewing/downloading;
- projects/deep dives;
- AI chat;
- Conversation Mode;
- project-scoped AI;
- Job Fit Analyzer;
- AI Lab public demos;
- public evaluation dashboard;
- social copy/open.

## Authenticated USER
Authentication must not unlock core portfolio information. Optional account conveniences may be added later only through a feature flag.

## Privacy
Guest chats are ephemeral by default. Do not create a shadow user account or fingerprinting identifier for portfolio usage.

## Acceptance
A fresh private browser window can complete all recruiter journeys.
