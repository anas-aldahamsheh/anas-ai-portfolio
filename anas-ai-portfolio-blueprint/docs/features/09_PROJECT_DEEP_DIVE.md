# Project Deep Dive

Each project page is content-driven.

Recommended blocks:
- overview;
- problem;
- constraints;
- solution;
- architecture;
- implementation;
- tech stack;
- challenges;
- trade-offs;
- results;
- screenshots/media;
- repository/demo links;
- evidence;
- related projects;
- Ask AI About This Project.

Fields are optional; renderer must not leave broken empty headings.

The AI index stores project ID in every chunk derived from this page.
