# Social Profile Popover UX

Interaction:
1. visitor activates platform action;
2. popover opens near trigger on desktop, sheet/dialog may be used on constrained mobile;
3. account URL displayed with wrapping;
4. Copy button copies URL;
5. Open button opens canonical URL;
6. Escape closes;
7. focus returns to trigger.

RTL:
- layout direction follows locale;
- URL container uses safe LTR handling;
- icons remain visually correct.

No platform profile URL is hardcoded.
