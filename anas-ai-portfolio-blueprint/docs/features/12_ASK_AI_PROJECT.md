# Ask AI About This Project

Project page can launch a scoped AI panel.

## Hard scope
Retrieval filter includes `project_id = selected_project_id`.

This filter is enforced in retrieval configuration, not merely mentioned in a prompt.

## Optional global context
A configurable policy may allow limited global profile context when needed. Project evidence remains primary.

## UX
- scope badge;
- project title;
- exit scope;
- suggested question concepts may be generated/configured dynamically rather than hardcoded owner-specific questions.
