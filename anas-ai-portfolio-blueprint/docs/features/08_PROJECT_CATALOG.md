# Project Catalog

Projects are database entities.

## Fields
Use structured metadata plus composable detail blocks:
- slug;
- localized title/summary;
- status;
- categories;
- tags;
- technologies;
- dates;
- featured flag;
- sort order;
- repository/demo links;
- cover/media references;
- retrieval metadata;
- publish state.

## Public
- filters;
- search if enabled;
- responsive cards/list;
- accessible links;
- graceful missing media behavior.

Do not assume a fixed project count.
