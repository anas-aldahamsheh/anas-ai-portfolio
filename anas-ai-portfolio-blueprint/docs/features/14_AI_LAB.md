# AI Lab

Purpose: demonstrate AI engineering capabilities interactively.

Potential demo types are admin-configured:
- retrieval comparison;
- hybrid search;
- reranking;
- prompt evaluation;
- structured extraction;
- agent workflow visualization;
- citation verification.

## Safety
Each demo has:
- explicit input schema;
- limits;
- timeout;
- rate limit;
- public/private toggle;
- provider budget;
- sanitized output.

Do not ship fake demo results.
