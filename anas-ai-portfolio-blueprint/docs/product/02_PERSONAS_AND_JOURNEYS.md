# Personas and User Journeys

## Recruiter / Hiring Manager

Goal: assess relevance quickly.

Journey:
1. arrives as Guest;
2. scans home;
3. opens CV;
4. browses two projects;
5. opens AI;
6. chooses Recruiter conversation mode;
7. asks role-specific questions;
8. pastes JD into Job Fit Analyzer;
9. copies LinkedIn or GitHub;
10. leaves without ever needing an account.

## Technical interviewer

Goal: understand actual implementation depth.

Journey:
1. opens project;
2. reads architecture/trade-offs;
3. opens Technical conversation mode;
4. uses Ask AI About This Project;
5. views RAG debug metadata/evaluation dashboard where enabled;
6. opens GitHub.

## General visitor

Goal: understand profile and work without technical overload.

Uses General mode and normal pages.

## Administrator

Goal: operate site without code changes.

Journey:
1. signs in;
2. server verifies ADMIN;
3. admin enters edit mode;
4. edits content inline or opens control panel;
5. changes models/prompts/retrieval settings safely;
6. publishes;
7. reviews audit and evaluation status.
