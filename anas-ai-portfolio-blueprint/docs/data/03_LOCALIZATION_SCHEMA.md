# Localization Data

Initial locale rows:
- semantic locale code `ar`
- semantic locale code `en`

The visible language names are localized database content if shown publicly.

## UI text
`ui_text_key`
- id
- namespace
- key
- required
- description

`ui_text_translation`
- key_id
- locale
- value
- status
- version

## Completeness
Admin localization dashboard reports:
- missing Arabic;
- missing English;
- stale translations;
- draft translations.

## Direction
Direction derives from locale metadata (`rtl`/`ltr`), not from translated labels.
