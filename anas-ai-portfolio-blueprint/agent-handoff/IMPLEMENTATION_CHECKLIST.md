# Implementation Checklist

Before touching feature:
- read feature doc;
- read dependencies;
- mark tracker IN_PROGRESS;
- identify tests first.

Before commit:
- format;
- lint;
- typecheck;
- tests;
- inspect diff for secrets/hardcoded owner content.

Before DONE:
- Definition of Done;
- Arabic/English;
- RTL/LTR;
- light/dark;
- mobile/desktop;
- authz;
- error/loading/empty;
- docs;
- tracker evidence.
